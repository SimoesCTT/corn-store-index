About Corn Store

What this is, what it isn't, and how it works.

Corn Store is a public index of free and open-source Android applications distributed through GitHub Releases. It catalogs apps that publish a signed APK as part of a GitHub release, so users can find and install them without going through a proprietary app store.

The index is regenerated every day by an automated scraper running on GitHub Actions. The scraper searches GitHub for repositories matching a set of topics (android, kotlin, fdroid, foss-android, and others), checks each repository's latest release for a signed APK, extracts metadata from the APK, and writes the result to a public JSON file.

What Corn Store is not:

  • Not a Play Store replacement. It's a niche index of FOSS apps.
  • Not a curated review process. Inclusion is automatic based on published topics and signed releases.
  • Not a marketplace. Nothing is sold here.
  • Not a company. No one is employed by Corn Store.

Privacy. This site has no accounts, no cookies, no analytics, no tracking, and no third-party scripts. The only network requests it makes are to fetch index.json (from this same domain) and app icons (from this same domain or github.com).

How to get an app indexed. See the Submit an app page.

Source code. The scraper and this site live at github.com/SimoesCTT/corn-store-index. Licensed GPL-3.0-or-later.
