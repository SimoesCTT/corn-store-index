Submit an app

Corn Store indexes automatically. No form, no email, no review queue.

The index is regenerated every day by a scraper that walks GitHub. There is no submission process. If your app is set up the way the scraper expects, it will appear in the index on the next daily run.

The scraper picks up a repo when it:

  • Is public on GitHub.
  • Has at least one of the topics the scraper searches for — commonly android, android-app, fdroid, foss-android, or kotlin.
  • Has at least one tagged release with an .apk file attached as a release asset.
  • Whose APK is signed with a release key (not the Android debug key).
  • Whose release is less than two years old (default recency window).
  • Whose APK is under 100 MB (current size limit).

Adding a topic. On your repo's main page, click the gear icon next to "About", and add one or more of the topics above. The scraper will pick them up on the next run.

Publishing a signed release. In Android Studio, generate a release keystore, configure signingConfigs in app/build.gradle.kts, and run ./gradlew assembleRelease. Attach the resulting app-release.apk to a GitHub release. See the "Building" section of any of the indexed apps' READMEs for a working example.

Verifying you were indexed. Search the home page for your app's package name. If it appears, the scraper found you. If it doesn't, either one of the criteria above isn't met, or the scraper hasn't run since you published.

Removal. If you want your app removed from the index, open an issue at github.com/SimoesCTT/corn-store-index/issues with the repo name and the word "removal" in the title. It will be added to the blocklist on the next scraper run.
