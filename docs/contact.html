Contact

How to reach the project.

Bug reports, feature requests, corrections:
Open an issue at github.com/SimoesCTT/corn-store-index/issues.

Removal requests:
If you are the developer of an app listed in the index and want it removed, open an issue at the same URL with the repository name and the word "removal" in the title. It will be added to the blocklist on the next scraper run.

Everything else:
The project does not maintain an email address. All communication goes through GitHub issues. This keeps the conversation public, searchable, and useful to anyone who runs into the same question.
