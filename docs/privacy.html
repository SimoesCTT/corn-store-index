Privacy

Effective 2026-10-11.

Corn Store does not collect any data about you.

This website. The site is a set of static files served by GitHub Pages. It uses no cookies, no analytics, no tracking pixels, and no third-party scripts. It makes two kinds of network requests:

  • Fetching index.json from this same domain to render the app list.
  • Loading app icons from this same domain, or from github.com when an icon is not bundled locally.

Logs. GitHub Pages, like every web server, records the IP address of every request in its access logs. That logging is done by GitHub, not by Corn Store, and is subject to GitHub's privacy policy. Corn Store does not have access to those logs and does not read them.

The Android app. The Corn Store Android app declares the INTERNET permission in order to fetch the index and download APKs. It does not declare any other permission. It does not have accounts, logins, or user identifiers. It does not include analytics, crash reporting, advertising, or telemetry of any kind. It stores the downloaded APK files in its own cache directory and deletes them when the app is uninstalled.

The scraper. The scraper runs on GitHub Actions and only reads public GitHub data. It does not see or process any user data, because there are no users.

Children. The site and app are not directed at children and do not collect data from anyone, of any age.
